# 03 · 几何、对齐与字体

> 数值来自官方 `docs/ui-radius.zh.md` 与 `ui-primitives` 的 CSS Modules（0.2.3-alpha.2）。官方原则：**先看渲染结果，再谈数值**；token 合法不等于这个组件该用它。

## 圆角尺度

| 用途 | 典型高度 | 圆角 | token |
|---|---|---|---|
| 小细节（键帽、行内代码） | < 20 | R4 | `--dsw-radius-xs` |
| 紧凑控件（小按钮、紧凑图标按钮） | 20–28 | R8 | `--dsw-radius-sm` |
| 标准控件/单行 cell（按钮、输入、选择器、导航行） | 32–40 | R12 | `--dsw-radius-md` |
| 大控件/分组内容 | — | R16 | `--dsw-radius-lg` |
| 独立内容卡片（设置卡片、气泡） | — | R20 | `--dsw-radius-xl` |
| 主容器（输入框卡片、对话框、主面板） | — | R28 | `--dsw-radius-panel` |

不要为单个组件发明 10/14/18/24px；也不要把所有按钮做成胶囊。

## 控件尺寸（不要改）

| 控件 | 几何 |
|---|---|
| `Button` md | 高 36，R12，字号 14/22，左右内衬 14 |
| `Button` sm | 高 28，R8，字号 12/18，左右内衬 10 |
| `Input` | 高 32，R12，内衬 `0 8px`，字号 14/22 |
| 选择器行 | 高 36，R12 |
| `Switch` | 36×20，内衬 2，轨道胶囊 999，滑块 16 正圆 |
| `SegmentedControl` | 外层 R12、内衬 4；段高 28、R8、字号 13/20 |
| `SegmentedTabs` md | 外层 R16、内衬 4；tab 高 34、R12、字号 14/20；总高 42 |
| `SegmentedTabs` sm | 外层 R14、内衬 2；tab 高 30；总高 34 |
| 菜单（标准） | 外层 R16、内衬 4；行 R12 |
| 菜单（紧凑） | 外层 R12、内衬 4；行 R8 |
| 设置卡片 | R20 + 0.5px 描边 + 卡片底 |
| `Pill` | 高 24 胶囊 |

圆角继承主题的超级椭圆曲线（`corner-shape`）：不要给单个组件加平滑规则；声明 `border-radius: 50%` / `999px` 时同一规则里配 `corner-shape: round`。

## 嵌套与贴边

| 关系 | 规则 |
|---|---|
| 同心内缩 | 内层 R = max(0, 外层 R − 内缩)；圆弧严格，超级椭圆按名义尺寸，仍需看对角空隙 |
| 底色贴容器 | 由外框决定可见圆角，裁切或继承，不要单独给底色加圆角 |
| 容器内独立卡片 | 按自己的用途选档，不机械减去父级 padding |
| 贴边停靠 | 外露拐角有圆角，内部拼接处保持直角 |

## 对齐

先选**对象**和**基准**，再量：

| 对齐方式 | 用于 | 常见错误 |
|---|---|---|
| 左边缘 | 导航文字、列表标题、字段标签、正文 | 每个组件各自一个“合理”的缩进 |
| 水平居中 | 独立主按钮、空状态 | 只居中文字，图标留在外面 |
| 垂直居中 | 单行图标+文字、工具栏 | 盒子等高，但 SVG 留白不同，视觉偏 |
| 基线/首行 | 混排字号、多行标签前的图标 | 图标对整段多行文字居中 |
| 双边缘 | 标题/操作行、左右分组 | 把每个图标均匀铺满宽度 |
| 重复列 | 操作簇、时间戳、文件行 | 只有最后一个对齐 |

图标有完整布局盒：视觉留白属于盒子，不要因为「看起来没对齐」就去掉。改容器、槽位、列、gap 之前，不要做光学微调。

## 间距

- 先分组，再决定 gap：标题+说明是一组，三个操作是一组，成员卡片是另一组。
- 组间必须明显大于组内；没有分隔线时，这条是底线。
- 标题离自己的内容，要比离上一组更近。
- 比较的是**渲染后的可见空白**（含 padding、line-height、字形留白），不是 CSS margin 数字。
- 官方不定义统一数值刻度：复用当前页面/最近同类组件的间距，不要为每个块发明一套。

## 字体

- 正文/控件 14/22；细节行 13/20（官方把 13px 作为行/详情基准）；小号 12/18。
- 字重只用 400 / 500；强调用字号或墨色，不用 600+。
- 等宽文本用 `--ds-font-family-code`，不要写字体栈。
- 语言、字号设置由用户控制：不要写死 `font-size: 13px` 到需要跟随界面字号的正文；用继承或主题变量。

## 图标

- 默认 16px；紧凑 12/14；警告标题 18。
- Regular 线稿保持 1 CSS px 描边，Medium 1.3px；不要改全局渲染行为。
- 复用现有图标；不重画共享字形；确需新图形时说明最近替代与缺口。

## 验证

1. 在实际页面按真实尺寸看，不只看 Figma/截图缩略。
2. 同时看浅色/深色、hover/选中/禁用/焦点。
3. 看窄容器、长文案、换行、裁剪。
4. 对照最近的原生同类控件：高度、圆角、内衬、字重、图标盒是否一致。
